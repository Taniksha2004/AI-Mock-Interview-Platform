# 🎓 AI Mock Interview Platform
It is an intelligent voice assistant designed to enhance student learning through real-time, interactive conversations. It allows students to ask questions using their voice, provides instant AI-generated answers, and supports follow-up discussions in a chat-like interface. The assistant also generates study notes and personalized feedback based on each interaction.

Key features include:
- **Voice Input for Queries**: Students can speak naturally, and the assistant transcribes and understands their questions.
- **Instant AI Responses**: The assistant provides clear, informative replies to help clarify concepts.
- **Text-to-Speech**: Bot responses can be played back as audio.
- **Study Note Generation**: Automatically creates summarized notes from discussions to support revision.
- **Quick Fix Suggestions**: Offers grammar and subject-specific corrections for better understanding.
- **History Tracking**: Saves all conversations, feedback, and notes in the user’s dashboard for future reference.
- **Discussion Room UI**: Provides an organized space for in-depth learning or group-based interaction.
- **User Profiles & Progress**: Tracks token usage, displays feedback, and allows updates to user information.

This makes EduVoice AI a powerful tool for accessible, personalized, and interactive education.
